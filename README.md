# OpenForge
OpenForge is a open-source and open-contribution rewrite of the [MonkeForge](https://monkeforge.org) API and website in C#.

As of now, it is a work-in-progress.

## Installation
OpenForge is distributed over GitHub releases and on our website.

## History
### Why?
MonkeForge was originally written in Python, which has seen some performance improvements over the years, but when handling upwards of 300,000 requests a day, it was evident that we needed to step it up.

This time, we write it in C#, most well known for Gorilla Tag modding but also turns out to be a good general-purpose language.
